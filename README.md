# Guide de l'entrepreneur novice en Belgique

Page web unique (`index.html`), autonome et responsive, présentant les étapes pour lancer une activité indépendante ou une société en Belgique : forme juridique, inscription BCE, TVA, caisse d'assurances sociales, assurances, aides régionales, erreurs fréquentes, et une checklist interactive sauvegardée dans le navigateur.

## Voir le site en ligne

Une fois cette branche fusionnée sur `main`, le site se déploie automatiquement sur GitHub Pages via le workflow `.github/workflows/deploy-pages.yml`.

**Étape unique à faire manuellement (une seule fois)** : dans les réglages du dépôt GitHub, aller dans **Settings → Pages** et choisir comme source **"GitHub Actions"**. Le workflow se charge ensuite de tout à chaque push sur `main`.

Le site sera ensuite accessible à l'adresse :
`https://incognitoresolve-alt.github.io/hub-hub/`

## Développement local

Aucune dépendance : ouvrez simplement `index.html` dans un navigateur.
